# Tổng quan về [[backup]] & [[RESTORE]]
- [[backup]]: tạo ra bản sao data dể dự phòng- có 3 loai:`full backup`, `differential backup`, `transaction log backup` 
- [[RESTORE]]: dùng bản sao đó để khôi phục dữ liệu 

**khi nào cần restore**
- xóa nhầm dữ liệu
- database bị lỗi
- server hỏng
- bị mất dữ liệu
- cần khôi phục về trạng thái trước đó
